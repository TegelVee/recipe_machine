# recipe_machine
[Still in progress]
A tool for maintaining a list of my favorite recipes and randomly selecting one recipe per day based on given constraints.

The .py file contains my favorite recipes, a random pick up, and values that have to be fulfilled while choosing foods for one week. As the result, the code produces a recipe list for one week, e.g.

VIIKKO 2

ma - Gnocchivuoka (30 min): https://www.valio.fi/reseptit/gnocchi-tuoremakkaravuoka/

ti - Mojo ja perunat (30 min): https://www.meillakotona.fi/reseptit/punainen-kastike-mojo-picon

ke - Tortellinipannu (20 min): https://www.instagram.com/p/DPCAegJjPC7/

to - Bouillabaisse-tuorepasta (45 min): https://www.hs.fi/ruoka/reseptit/art-2000008522713.html

pe - Pinaattikeitto (15 min): pakasteesta

la - Filee ja perunat (30 min): ulkomuistista

su - Nakkikastike ja muusi (30 min): ulkomuistista
